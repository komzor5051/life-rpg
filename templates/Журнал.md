# Журнал

Одна строка на событие. Кабинет читает поля в квадратных скобках. Новые записи в конец.

Типы:
- `money` деньги поступили или договорённость подписана. Поля: d, sum, src
- `sale` действия, ведущие к деньгам. Поля: d, n, src
- `content` публикации. Поля: d, n, src
- `practice` практика. Поля: d, hours, src
- `system` сессии и коммиты, пишет ночной скрипт. Поля: d, n
- `day` вечерняя запись. Поля: d, energy, src

Образец строки:

    - [type:: money] [d:: 2026-01-15] [sum:: 14000] [src:: Консультация, Анна]
    - [type:: sale] [d:: 2026-01-15] [n:: 5] [src:: Личные сообщения]
    - [type:: day] [d:: 2026-01-15] [energy:: 7] [src:: Бросил правку сайта, это рюкзак]
